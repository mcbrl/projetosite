A plataforma Liferay DXP possui uma ferramenta robusta que possibilita a criação de sites para internet e/ou intranet de forma prática, flexível, multi idiomas, além de muitos outros recursos, e dentre estes recursos existe a otimização para o SEO (Search Engine Optimization).

Dentro de uma empresa existem diversas estratégias que podem ser tomadas para atrair mais clientes e a criação de conteúdos orgânicos é um deles. Quando falamos de SEO, as empresas precisam se preocupar com questões que vão muito além do conteúdo de qualidade, ter uma plataforma segura e eficiente é fundamental.

Mas é possível ter um portal leve, com uma experiência de usuário satisfatória e otimizado para SEO? A resposta é, sim!

Para otimizar o conteúdo de forma que ele seja alcançado organicamente é uma simples de ser configurada no portal Liferay, para isso basta seguir alguns passos para a implementação.

Veja o artigo produzido pelo nosso arquiteto de software, Henrique Andrade e saiba como configurar a sua plataforma Liferay!

## Configurando Liferay DXP para sua estratégia SEO

Uma vez com a página criada e seu conteúdo pronto para dar início a sua estratégia SEO com [Liferay DXP](/dxp-cms-ou-portal-qual-a-melhor-ferramenta-para-criar-jornadas-digitais-impactantes/), o gestor pode acessar a área de definição dos atributos que serão especialmente utilizados pelas ferramentas de busca.

No exemplo abaixo temos uma parte dos campos que podem ser preenchidos a fim de personalizar como a página deverá ser apresentada:

![](/wp-content/uploads/2023/04/SEO_1.png)

Todos os atributos comuns ao SEO estão disponíveis para preenchimento, há também uma pré-visualização de como a página será apresentada na ferramenta de busca:

![](/wp-content/uploads/2023/04/SEO_2.png)

Para portais com internacionalização é possível definir o conteúdo específico (traduzido) para cada idioma, bastando clicar na bandeira ao lado de cada campo e preencher:

![](/wp-content/uploads/2023/04/SEO_3.png)

## Liferay DXP Open Graph

Além de um ajuste fino para SEO especificamente, o portal Liferay disponibiliza outro recurso muito importante para qualquer site que necessita de uma boa apresentação em rede social.

Na configuração da página é possível definir atributos específicos em um formulário amigável, e uma vez preenchidos, todas as tags necessárias de acordo com a especificação Open Graph serão adicionadas na página de forma transparente para o gestor.

No exemplo abaixo temos o formulário com os campos que podem ser definidos, inclusive para cada idioma através da bandeira:

![](/wp-content/uploads/2023/04/SEO_4.png)

Após preenchidos os campos necessários, será exibida uma pré-visualização de como a página poderá ser exibida em uma timeline do Facebook por exemplo:

![](/wp-content/uploads/2023/04/SEO_5.png)

## Marcadores (meta) personalizados

Além das configurações de SEO e Open Graph, é possível adicionar de forma prática meta tags adicionais à página caso seja necessário, sem precisar editar código HTML diretamente, bastando acessar a funcionalidade “Marcadores personalizados” e preencher conforme a necessidade, podendo ter várias tags e além de ser internacionalizado:

![](/wp-content/uploads/2023/04/SEO_6.png)

## HTML gerado automaticamente

Caindo mais para o lado técnico, estes atributos serão incluídos automaticamente na página após os campos do Open Graph e/ou SEO forem preenchidos para a página:

## Análise de SEO integrada com Google PageSpeed Insights

É possível no portal Liferay configurar o site para utilizar a sua chave da API Google [PageSpeed Insights](https://pagespeed.web.dev/), e após configurada chave o gestor de conteúdo do site poderá ter de forma integrada com o portal a prévia do desempenho das páginas.

No exemplo abaixo temos um resumo dos principais pontos identificados pelo Google PageSpeed Insights, podendo ser visualizados diretamente pelo portal:

![](/wp-content/uploads/2023/04/SEO_8.png)

Por exemplo, vamos analisar o item **“Textos de link”**:

![](/wp-content/uploads/2023/04/SEO_9.png)

Assim, os seus links terão a descrição para facilitar a indexação nos motores de busca, aumentando assim a relevância do conteúdo desenvolvido.
