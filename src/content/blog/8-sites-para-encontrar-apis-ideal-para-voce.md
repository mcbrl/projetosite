Elaboramos uma lista com 8 sites para te ajudar a encontrar APIs que executam diversos tipos de soluções na construção do seu projeto de TI. Além disso, também fizemos um review de cada site para te orientar.

Se você já sabe [o que é uma API](/o-que-e-api-entenda-de-uma-maneira-simples/), confira através deste conteúdo como um [API Gateway e um API Manager](/api-gateway-ou-api-management/) podem potencializar seu uso .

Aproveite também para conferir o post onde falamos sobre [“4 Dicas para aumentar o engajamento na sua API”](http://blog.vertigo.com.br/4-dicas-para-aumentar-o-engajamento-na-sua-api/?_fs=c9fcaf60-1bbe-4917-9b91-b09869a8dc77). Se você vai começar uma estratégia de **API**, precisa ter alguns modelos como referência.

Voltando para o trilho, listamos a seguir 8 sites que podem te ajudar bastante com essa missão.

## 1: [ProgrammableWeb](http://www.programmableweb.com)

Ao acessar o site, o usuário tem acesso aos comunicados relacionados às Interfaces de Programação de Aplicação, reportagens, comentários.

Ao acessar a página existe a possibilidade de aproveitar **o maior diretório de APIs do mundo**! Além disso, o site também cataloga mashups e ferramentas de desenvolvimento, para SDKs, frameworks, bibliotecas e amostras de código.

[![](/wp-content/uploads/2018/03/PW.png)](http://www.programmableweb.com)

Eles também produzem conteúdo próprio sobre as APIs, publicando artigos sobre atualizações, tutoriais de código, comentários e etc. Através de dados internos e pesquisas de mercado, eles também fornecem conteúdo relevante sobre [a Economia das APIs](http://blog.vertigo.com.br/parte-1-a-economia-das-apis-ja-esta-aqui-voce-esta-pronto/?_fs=c9fcaf60-1bbe-4917-9b91-b09869a8dc77). Vale a pena ter esse site entre os seus favoritos!

## 2: [PublicAPIs.com](https://www.publicapis.com/)

Os visitantes podem pesquisar e comparar as funcionalidades entre as diversas APIs existentes entre elas da Nasa, Paypal entre outras.

É possível incluir pequenas descrições e links para a documentação de quem as desenvolveu, se você quer criar a sua API e não tem nenhuma como referência, é bem possível que você encontre uma solução para iniciar o seu projeto.

[![](/wp-content/uploads/2018/03/publicapis.com-API-discovery-nordic-apis-1024x634-1.png)](https://www.publicapis.com/)

Os visitantes também podem sugerir novas interfaces de programação de aplicação para expandir o diretório.

## 3: [APIs.io](http://apis.io/)

Este site é mantido por 3Scale, API Evangelist, e API Tools. Eles utilizam a busca por metadados para encontrar a API que você está procurando. Por conta desse modelo de busca, ele é destacado como uma alternativa escalável para os modos tradicionais de catalogação API.

O site é referência no mundo da tecnologia e está listado como uma das principais fontes de busca confiáveis por especialistas. 

[![](/wp-content/uploads/2018/03/apis.io-API-discovery-nordic-apis.png)](http://apis.io/)

## **4:** [**Algorithmia**](https://algorithmia.com/algorithms)

O site tem como destaque a possibilidade de matemáticos disponibilizarem seus algoritmos para o desenvolvimento de ferramentas inteligentes. As soluções de integração entre aplicativos através que utilizam machine learning  na área de áudio, vídeo e matemática são aproveitadas em outros projetos. Isso torna o site um excelente repositório de APIs.

[![](/wp-content/uploads/2018/03/algorithmia.png)](https://algorithmia.com/algorithms)

## **5:** [**Product Hunt**](https://www.producthunt.com/#!/s/posts/api)

Através de uma comunidade colaborativa semelhante ao Reddit, diversas APIs são compartilhadas e organizadas em listas.

Para quem procura um ambiente informativo e com informações atualizadas, o site é uma excelente opção na busca por soluções inteligentes.

[![](/wp-content/uploads/2018/03/producthunt.png)](https://www.producthunt.com/)

## 6: [Google APIs Discovery Service](https://developers.google.com/discovery/)

Esse site reúne várias APIs do Google e retorna dados sobre elas através de uma “API leve, baseada em JSON que expõe metadados legíveis por máquina.” Essa ferramenta fornece a visão interativa tanto para máquinas quanto para os olhos humanos.

A experiência do usuário é aprimorada através de um vídeo explicativo durante o acesso. Vale a pena conhecer!

[![](/wp-content/uploads/2018/03/google-apis-discovery.png)](https://developers.google.com/discovery/)

## **7:** [**API Harmony**](https://apiharmony-open.mybluemix.net/public)

Navegue pelo diretórios de APIs da IBM e descubra soluções que atendem satisfatóriamente em diversos contextos.

O site é organizado em listas e destaca as APIs mais populares, além disso, tem o espaço para o debate entre desenvolvedores e projetos do GitHub.

[![](/wp-content/uploads/2018/03/apiharmony.png)](https://apiharmony-open.mybluemix.net/public)

**8:** [**Azure Marketplace**](https://docs.microsoft.com/pt-br/azure/?product=featured) **by Microsoft**

São APIs que giram em torno da Microsoft Azure, uma plataforma dedicada à execução de diversos aplicativos em nuvem para a construção de projetos inovadores em busca da [transformação digital](/transformacao-digital-voce-esta-pronto/). Você pode realizar o seu cadastro gratuito na plataforma.

É possível acessar a API para diversas soluções, inclusive Kubernetes do Azure. Se você é desenvolvedor, encontrará material de qualidade ao navegar pelo site.

[![](/wp-content/uploads/2018/03/azure-microsoft-nordic-apis.png)](https://docs.microsoft.com/pt-br/azure/?product=featured)

## **Quero saber mais sobre API!**

As APIs estão cada vez mais presentes na nossa economia atual. A maneira como a tecnologia é catalogada e encontrada torna-se uma preocupação crescente, afinal, o que não é encontrado não é usado. Simples assim!

É interessante que o pensamento com relação ao uso de uma **API** seja o mesmo do que de um produto. Os desenvolvedores devem considerar todas as ações possíveis de marketing (Sim, Marketing e TI devem pensar juntos uma estratégia de API). Neste espaço, as estratégias de Marketing Digital são fundamentais. Uma dica bem simples: busque diretórios como esses que foram citados para adicionar a sua API e aumentar a exposição e relevância dela!
