## A virtualização das APIs

A produção de uma nova **API** – seja ela [pública ou privada](http://blog.vertigo.com.br/api-publica-ou-privada-como-saber/) – pede um certo cuidado na garantia de que ela consiga realizar sua função com eficiência. Dependendo do objetivo da empresa, uma API pode ser responsável por transações financeiras ou somente por exibir informações de um perfil de uma rede social, mas no caso de erros o resultado pode ser catastrófico.

Alguns problemas simples que podem comprometer a segurança e o funcionamento de uma empresa conseguem ser facilmente prevenidos com um conselho simples: **teste sua API**. Mas para que isso seja feito você precisa primeiro implantá-la completamente, certo? 

Na verdade não: existe uma forma de criar um ambiente seguro e econômico para esses testes, e esse processo é chamado de **virtualização das APIs**. Ambientes de simulação não são um conceito estranho em desenvolvimento web. Especialmente quando se fala em APIs, que por vezes, precisam simular uma parte do seu serviço para fins de teste, é nesse caso que a virtualização é uma opção que pode ir além de apenas testar a sua API.

Seguindo o mesmo conceito do [Dropbox API](http://www.programmableweb.com/news/dropbox-releases-api-explorer-to-test-api-calls/2015/08/21), a[Amazon](http://www.programmableweb.com/news/amazon-announces-mock-integration-feature-api-gateway/brief/2015/09/03) anunciou recentemente um recurso de integração de simulação para seu gateway API. Virtualização leva essa simulação a um passo adiante, permitindo chamadas de API e respostas simuladas para serem codificadas na etapa de desenvolvimento, permitindo assim que provedores e desenvolvedores de APIs possam mensurar o desempenho de maneira bastante refinada antes do lançamento oficial.

## O que é virtualização das APIs?

Virtualização é quando um ambiente é criado para simular um *software* funcionando com base em outro programa. Isso é muito visto com sistemas operacionais virtuais, como programas que permitem ao Windows funcionar dentro do OSX ou o Android dentro do iOS, por exemplo.

No caso da virtualização das [APIs](/o-que-e-api-entenda-de-uma-maneira-simples/) as coisas são um pouco diferentes: como muitas APIs trabalham com plataformas em nuvem, é necessário simular esses sistemas para que seja possível testá-las sem que seja feita a integração com o sistema original. Aplicar essa idéia traz algumas possibilidades e vantagens para os desenvolvedores, e vamos mostrar 5 delas para que você entenda um pouco melhor porque a virtualização das APIs pode ser interessante.

## 1. Teste sua API em um ambiente seguro

Uma API com mal funcionamento pode simplesmente não cumprir sua função, mas também é possível que ela interfira com outros processos do sistema e gere dificuldades para os usuários. Ao realizar testes através da virtualização das APIs você consegue evitar problemas maiores, além de entender o comportamento da API e mapear problemas antes que outros usuários possam encontrá-los, e buscar maneiras de remediar essas falhas. 

## 2. Teste sua API simulando problemas

Já viu como as mensagens de erro de função aparecem para o usuário? Como funciona os limites de frequência? Durante as etapas finais do desenvolvimento, é importante saber como a sua API responde a erros e problemas do sistema. Para que isso seja possível a virtualização das APIs permite que você crie situações extremas através de simulações, e que assim você possa analisar mensagens de erro, falhas, e velocidade de resposta, por exemplo, para que seja possível corrigi-los. 

## 3. A virtualização das APIs aumenta sua produtividade

Com a virtualização das APIs, seus desenvolvedores não precisam perder tempo programando testes específicos para avaliar uma API, e podem dedicar esse tempo a melhorar a integração e a corrigir erros encontrados através da simulação.

## 4. Testes com a virtualização das APIs são econômicos

Economizar o tempo dos desenvolvedores para que eles consigam produzir de forma mais eficiente também é economia, pois os projetos demoram menos, e é possível desenvolver mais soluções em menos tempo. Também é interessante levar em consideração o maior benefício de realizar testes através da virtualização das APIs: menos erros que fariam com que a plataforma ficasse indisponível, menos gastos com reparos, e a possibilidade de prever problemas e resolvê-los antes que ocorram.

## 5. Sua API fica pronta antes

Através da junção dos benefícios anteriores, a finalização mais rápida é o que traz mais agilidade para um negócio. Os desenvolvedores conseguem trabalhar com mais eficiência e corrigindo erros importantes, o que faz com que sua API esteja pronta para ser integrada – sem riscos ao sistema – num período de tempo muito inferior ao que seria necessário sem os testes com a virtualização das APIs.

## Conclusão

#### Benefícios da virtualização API

Virtualização das API traz alguns benefícios, tais como:

- O aumento da produtividade;
- Menor tempo para lançar sua API no mercado;
- Testar cenários do mundo real, sem o risco;
- Eliminar a necessidade de desenvolvedores individuais para escrever e reescrever suas próprias simulações.

Experimente essa solução e teste sua API com a virtualização, assim você consegue mais eficiência e economia, com mais segurança para seus sistemas.
