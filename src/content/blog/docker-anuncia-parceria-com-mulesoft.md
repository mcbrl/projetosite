Docker e MuleSoft juntas?

Parece que vem coisa boa por aí!

Recentemente a [Docker](/docker/) anunciou uma parceria com a [MuleSoft](/mulesoft/) que promete potencializar o processo de transformação digital de seus clientes.

Uma convergência de forças entre SaaS, IoT, Cloud e Mobile trouxe exigências sem precedentes para que empresas acelerem sua inovação e atendam as demandas em constante mudança.

*Não é o peixe grande que come o peixe pequeno. É o peixe rápido que come o peixe lento.*

Já foram disponibilizadas várias soluções para esse problema de aceleração – desde o trabalho mais árduo até a terceirização e o [**DevOps**](/o-que-e-devops/). Porém, nenhuma dessas soluções realmente ofereceu os níveis de aceleração necessários. E o motivo é claro: há muito atrito retardando as possibilidades.

**Docker** e **MuleSoft** eliminam o atrito no processo de inovação, desde a concepção até a implantação.

O MuleSoft oferece uma abordagem arquitetônica “top-down”, com projeto e implantação **“API-first”** (API em primeiro lugar).

A abordagem do Docker é **“bottom-up”**, quando vista a partir da perspectiva da conteinerização de aplicações, tanto ao modernizar os aplicativos tradicionais quanto ao criar aplicativos novos.

![](/wp-content/uploads/2018/11/DOCKER-imagem.png)

O casamento dessas duas abordagens, combinado com plataforma, ferramentas e metodologia propostos, permite que ambas organizações ajudem sua empresa a se modernizar mais rápido do que nunca.

Docker e MuleSoft eliminam o abismo entre a infraestrutura e os serviços de uma maneira jamais alcançada na indústria.

Docker e MuleSoft juntos aceleram a modernização de sistemas legados e a entrega de novos aplicativos, reduzindo a complexidade e os custos da TI.

 Com ambos é possível atingir os seguintes objetivos:

1) Modernizar aplicativos tradicionais rapidamente, sem alterações de código, com a metodologia e as ferramentas da plataforma de containers Docker Enterprise usadas para conteinerizar as aplicações legadas.

Em seguida, você pode estender instantaneamente sua lógica de negócios e os dados para novos aplicativos, aproveitando o API Gateway e o Anypoint Platform da MuleSoft.

[API Gateway ou API Manager? Saiba quem é quem.](/api-gateway-ou-api-management/)

2) Acelerar o tempo de lançamento de novos aplicativos, aprimorando a produtividade e a colaboração do desenvolvedor e permitindo uma maior reutilização de serviços de aplicativos.

O **Anypoint** **Studio** permite que você defina contratos de API e desacople consumidores e produtores de microsserviços, para que os desenvolvedores de linha de negócios que consomem a API possam começar a criar inovações imediatamente (como um aplicativo móvel) usando serviços **“mockdados”** no Anypoint.

O Docker Desktop é usado hoje por milhões de desenvolvedores para desenvolver microsserviços usando qualquer linguagem e estrutura.

Os desenvolvedores de microsserviços podem aproveitar o **Docker Desktop** para implementar as APIs usando a melhor ferramenta para o trabalho e se concentrar na implementação da lógica de negócios com uma especificação clara, definida no Anypoint Platform.

Isto permite que o **Anypoint Platform** forneça mais uma camada de segurança, observabilidade e capacidade de gerenciamento no nível da API.

3) Melhorar a segurança geral do aplicativo, a capacidade de gerenciamento e a observação usando o **Docker Enterprise** para gerenciar as cargas de trabalho do container e o MuleSoft Anypoint Platform para executar e gerenciar a rede do aplicativo.

![](/wp-content/uploads/2018/11/DOCKER-imagem.png)
Com essa parceria, a Docker e a MuleSoft prometem uma solução completa, ferramentas, metodologia e know-how, para executar uma abordagem multifacetada para promover uma transformação profunda no seu negócio.
