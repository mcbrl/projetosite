**Liferay's Digital Experience Platform** for building portals, intranets, and mobile apps continues to revolutionize operations for numerous companies in Brazil and worldwide, enabling business growth in countless segments. We at **Vertigo Tecnologia** have already closely followed these potentialities with the [Carioca Digital utilities portal](/en/Vertigo--a-liferay-from-Rio-de-Janeiro--digital./).

Liferay **DXP** has many functional features that redefine the meaning of the word "customer experience." If you were already familiar with the tool, know that what was already good has become even better. As we at the **Vertigo Tecnologia blog** want to keep you updated on everything, we've highlighted some key points of the new version. Check them out below!

## **The look and feel of Liferay DXP**

Liferay **DXP** spared no effort in improving the user experience. The organization of pages, the implementation of new ways to use content, and applications on a single page were some of the changes, which you can see in more detail below.

### **New default theme**

The default theme for websites (known as *classic* ) has been updated to provide a modern, *mobile-friendly* , *flat* , and very clean look. The user experience and the experience for website owners has been greatly improved.

### **Predefined decoration for application and content.**

Increased possibilities for configuring the theme and navigation through the site administrator, rather than through a front-end developer.

### **Mobile SDK and Liferay Screens**

Liferay **DXP** offers an SDK for iOS and Android, in addition to Liferay Screens, which is another way to develop native mobile experiences.

### **Improved user interaction with the page.**

The latest version of the **Liferay** **digital platform** now supports @mentions for *blog entries* and has improved commenting capabilities to keep users engaged. The new blog authoring feature also provides a better user experience.

### **Improvements to the Blog, Forum, and Wiki**

The Blog, Forum, and Wiki also received incremental improvements focused on encouraging user engagement and usage.

### **Single Page Application**

Liferay **DXP** offers the ability to automatically convert any portlet into a Single Page Application, also known as an SPA. For example, a page with two portlets is converted into an SPA. This has resulted in a significant improvement in page response time, which has been drastically reduced from 2 seconds to 0,7 seconds.

Data traffic in a request decreased from 1.300 KB to 67.9 KB. The number of *requests* dropped from 42 to 11. The SPA will be applied to all portlets *out of the box* . Just for your information, **Liferay DXP** uses AngularJS, which provides features for building SPAs.

![](/wp-content/uploads/2018/05/liferay-dxp-construcao-1-1024x764-1.jpg)

### **New Forms**

Liferay **DXP** includes a new application that allows you to define and publish quite advanced dynamic forms. Forms can have complex multi-column layouts and be multi-page. They can be published on any Liferay site by simply placing the form on a page, or in the style of Google Forms by providing a URL that links directly to a full-page form.

Many field types have been included, but there is also the possibility of deploying custom modules. Forms can also be integrated into the Liferay *workflow* system to submit forms through a pre-modeled process.

### **Optimized Content Authoring**

Liferay **DXP** features the new WYSIWYG editor and Alloy Editor. In addition, some minor improvements have been added, such as the ability to organize web content into folders. Developers will also find differences in visual content, content structure reuse, and site templates.

### **Geolocation of any content**

Liferay **DXP** provides the ability to georeference all internet content. It is also capable of listing data, documents, and media. Another potential feature it offers is the ability to leverage the power of **Asset Publisher** , which allows you to create lists of geolocated content and publish them on a map.

### **Enhanced staging for the most advanced scenarios.**

Publishing from *Staging* to Production is now as easy as clicking a button. And for more advanced publishing scenarios, it's now possible to save advanced settings and reuse them later to ensure successful publications every time.

### **New image, file, and media selector.**

Liferay's new media selector is designed to simplify the most common operations. Furthermore, it's highly extensible, allowing new media sources like Google, Flickr, and YouTube to be added to any application using the selector.

### **Web content articles now require a structure and template.**

The web content article now requires a default Structure and Template, which are called Basic Web Content. These have been added to the portal's global scope and can be modified or deleted. This change gives users the flexibility to modify the default structure and template.

### **Faster startup**

To reduce platform startup time, **Liferay DXP** removed many standard portlets, features, and associated APIs such as OSGi modules, which reduced *startup time* while still allowing customers to use all of this on demand.

### **Support for OSGI**

OSGI support allows us to *hot deploy* packages without impacting the application. Another advantage is the ability to run different versions of the same application simultaneously.

### **Some changes to the Control Panel**

The changes to the control panel weren't many, which is good news for those who already use the platform and don't want to get lost when using the new version of the product.

One of the changes was the Dockbar in the control panel, which was replaced by the Liferay DXP menu button, located on the left side of the page.

One cool thing about this version is that **Liferay DXP** allows the user to change the page's appearance with just one click.
