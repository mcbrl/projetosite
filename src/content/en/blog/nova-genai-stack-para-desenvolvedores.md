## Before we continue, do you know what a graph database is?

When we talk about a graph database, we are referring to a systemic approach to data, highlighting the relationships between various data entities, and this type of database is advantageous in several situations.

Graph databases contain nodes, edges, and properties, which are used to represent and store data. This unique capability makes them ideal for representing and storing data in ways that traditional relational databases cannot.

We've prepared an article that explains in detail what a graph database is, its advantages, the existing types, and how it differs from a relational database. If you have any questions, you can [check it out here](/en/Graph-databases%3A-what-are-they-and-what-are-the-advantages-for-your-business/).

## Nova GenAI Stack in conjunction with Docker LangChain and Ollamma

Neo4j launched a new stack in October 2023 for building GenAI-powered applications in conjunction with [Docker](/en/Containerization%3A-The-Importance-of-Container-Management/) , LangChain, and Ollama.

The GenAI stack is a great way to quickly start building GenAI-powered applications. As such, the new technology includes Neo4j as the default database for vector search and knowledge graphs, and is available for free.

In this way, the platform was developed to empower teams of developers to specialize in building applications involving generative artificial intelligence in a simple way and in just a few minutes, reducing the level of complexity related to other technological integrations.

## The GenAI Stack presents 3 interesting points.

Emil Eifrem, CEO & Co-Founder of Neo4j, Inc., highlighted some key points about the GenAI Stack:

The technology is integrated with the core components needed for use, which are already integrated and configured for you in Docker containers.

The user experience becomes more enjoyable because it allows them to experiment with new models, hosted locally on their machine (like [Llama2](https://ai.meta.com/llama/) ) or via APIs (like OpenAI's [GPT](https://platform.openai.com/docs/guides/text-generation) ).

The GenAI Stack is already configured to help you use the [Retrieval Augmented Generation](https://neo4j.com/developer-blog/genai-app-how-to-build/) (RAG) architecture for LLM applications, which, in their opinion, is the easiest way to integrate an LLM into an application and give it access to its own data.

## Getting to know the LLM in more detail

As part of Neo4j's culture, teams are dedicated to understanding LLM-supported applications and the role graphs can play in them. Fundamentally, all data represents something in the real world, and virtually everything in the real world is connected in some way.

In this way, graphs can represent hidden patterns and complex relationships within the data, allowing GenAI models to better understand the world and, in particular, to understand their data and, through that, their worldview.

The powerful combination of graphs and LLMs is the reason why we see great acceptance and adoption of Neo4j for building LLM-supported applications.

Usage skyrocketed when we added native vector search as part of our core capability, combining the implicit relationships discovered by vectors with the explicit, factual relationships and patterns illuminated by graphs.

Neo4j also allows users to create knowledge graphs, which underpin LLMs in these factual relationships, enabling clients to gain richer insights from semantic searches and generative AI applications, and improve accuracy.

While LLMs excel in linguistic skills, they experience delusions because they lack a foundation in truth. Knowledge graphs solve this problem.

## Building the Full Stack

The Neo4j team employed a skillful strategy that combined the robustness of the Docker platform with the distinct strengths of graph database technology, enriched with native vector search capabilities and knowledge graphs.

The result was the creation of a standout solution for developers, allowing them to quickly implement GenAI in their projects. This included a programming and orchestration framework for LLMs (LangChain) and a system for the local execution and management of these LLMs (Ollama).

The Gen AI Suite is now readily accessible as a Docker Compose file, available in the Docker Desktop Learning Center and on [GitHub](https://github.com/docker/genai-stack).

It consists of several configurations, specifically designed to meet the most common GenAI use cases, and offers reliable open-source content through Docker Hub.

Among its features, highlights include open-source LLMs, pre-configured via Ollama, the graph database and knowledge graphs from Neo4j, LangChain orchestration, as well as a range of supporting tools, code templates, practical guidelines, and GenAI best practices.
