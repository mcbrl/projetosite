![](/wp-content/uploads/2019/04/imagens-internas2_1.jpg)

## Is containerization the best option?

Containers and virtual machines run both on-premises and in the cloud. Broadly speaking, what makes a container an evolution of a virtual machine is the fact that a container is more compact and therefore lighter and more supportable anywhere.

With Docker Enterprise, for example, it's possible to run containers on a **virtualized infrastructure** , while others run the same thing **on bare hardware**.

Below, we highlight the main differences between containers and virtual machines to illustrate some of the reasons why using containers can be more advantageous.
 [](/wp-content/uploads/imagens-internas2.jpg)

## 1\. Containers provide greater agility.

Does the saying, "It works on my machine..." sound familiar? With containers, developers and operators can definitively avoid this type of situation. After all, a container can be deployed quickly and provides an immutable infrastructure. In other words, what is configured in the container will rarely change, and if it does, it can be easily restarted.  

With regard to the correction process, they surpass the traditional process because they allow organizations to reduce response time to failures. This significantly improves the quality of applications, as well as their maintenance.
 [](/wp-content/uploads/imagens-internas2.jpg)

## 2\. Containers enable hybrid and multi-cloud adoption.

Once containerized, applications can be deployed on any infrastructure. This could be virtual machines, bare-metal, or various public clouds running different hypervisors. Many organizations start by running containers on their virtualized infrastructure and find it easier to migrate to the cloud without needing to change the code.

![](/wp-content/uploads/2019/04/multicloud-768x444-1.jpg)

## 3\. Containers integrate with legacy systems.

Most enterprise organizations have a mature virtualization environment, which includes tools for backups, monitoring, and automation, as well as the people and processes built around it. By running Docker Enterprise on virtualized infrastructure, organizations can easily integrate containers with legacy systems and reap the benefits described above, including points one and two.
![](/wp-content/uploads/2019/04/maquinas-virtuais-768x463-1.jpg)

## 4\. Containers save on VM licensing.

Containerized applications share the operating system and common software libraries, which greatly improves CPU utilization in a VM. This means an organization can reduce the total number of virtual machines needed to operate its environment and increase the number of applications that can run on a server. Docker Enterprise users typically see 50% greater server consolidation after containerization, which translates to lower hardware costs and savings on VM and operating system licensing.

## Why use containers on bare metal?

Just as organizations have reasons for using different servers or operating systems, there are reasons why some organizations want to run containers directly on bare metal. This is usually due to performance or latency issues, or for licensing and cost reasons.

## How does Docker increase container security?

Containers are inherently secure on their own. Docker containers create layers of isolation between applications and between the application and the host. This protects both the host and the containers while reducing the host's surface area.

Docker containers running on bare metal have the same high-level restrictions applied to them as if they were running in virtual machines. But Docker containers also combine well with virtualization technologies, protecting the virtual machine itself and providing defense-in-depth for the host.

## Containerization is good, but with Docker it's a success!

When choosing Docker to containerize their applications, the organization has the freedom to choose where it will run: virtual machine or basic hardware. The user will find this same freedom in all other data center options.

It's important to emphasize that technology is designed and developed to enhance your business. In this sense, it's a flexible tool that helps shorten the path between your goals and priorities and their execution.
