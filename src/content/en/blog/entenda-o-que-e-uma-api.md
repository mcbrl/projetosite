Do you know what an API is?*Application Program Interface*An API is an interface that allows communication between devices or systems. In the era of the Internet of Things, new business models, and new applications, APIs have become fundamental tools for enabling different systems and "things" to communicate. It's a "bridge" that connects system "A" with system "B". Developing a program or business model using technology, without using an API, can be extremely difficult for scaling your business.
APIs not only reduce the size of software and facilitate maintenance, but also make it more dynamic and less prone to errors.
Learn more about the topic and understand what an API is:

## **A bridge in the world of software.**

When you ask yourself **What is API?**Think of it as a bridge connecting two or more points. In other words, it's a smart gateway, programmed to allow developers to access certain data from an organization. When a developer creates a *app* Using GPS, it doesn't require programming lines of code that instruct the cell phone to connect to a satellite to obtain the coordinates of the user's location. In this case, the [Google Maps](https://developers.google.com/maps/?hl=pt-br) This is already available and developed, as is the case with 99, Uber, Cabify, Correios (Brazilian postal service), etc. Instead, these companies can simply type a command and call the Google Maps API. This way, the device's system application can request the device's current location. It would be something like a "*getLocation*".
Another example is social media registration. If we consider this type of scenario, where a website uses information from Facebook/Gmail to register new users, as is the case with TripAdvisor or Spotify, we will understand that this is only possible because of this integration.
Through APIs, the website sends a command to the servers, requesting the necessary information so that the new user can easily create an account. Without this feature, this type of website would have to develop registration forms, pages for creating new accounts, and a database to store all this information from scratch.
In this way, this site already uses everything it needs that is already present on Facebook/Gmail servers, only retrieving what is necessary for the new registration. It's important to remember that the more fields requested during registration or a sale, the greater the chance that the user will abandon the registration or purchase process. APIs also help with this.

## What are the different types of APIs?

Did you know that there's a difference in knowing what it is? **Private and public APIs**We will explain it in a very simple and quick way, about [Public and Private APIs](https://blog.vertigo.com.br/api-publica-ou-privada-como-saber)Any device (cell phone, PC, car, kiosk, website, app) with internet connectivity can use an API. This is independent of the operating system or programming language. This facilitates the construction of platforms and allows the creation of new business models much faster than before.
As **Public APIs** They are generally free or even structured as a plan. *freemium,* so that developers can use them. There is also a purchase option for a certain limit of calls per month. It is estimated that there are currently more than 15.000 public APIs.
Not all APIs are open to the public or even for any type of developer to use. Many APIs are used only internally, such as Netflix's use of a... **Private API,** which powers all video transmissions internally.
The commercialization of new businesses through the concept of developing APIs first has begun to take shape. This is also excellent for integrating with... **business partners.**

## **Examples of APIs**

For those considering creating APIs, there are open-source tools ( [Mulesoft](/en/partnerships/mulesoft?utm_source=BlogVertigo&utm_medium=Post&utm_campaign=EntendaAPI) , [WSO2](/en/partnerships/wso2?utm_source=BlogVertigo&utm_medium=Post&utm_campaign=EntendaAPI) ) and proprietary tools (Oracle, IBM, SAP, Tibco, RedHat, and others) that assist in this task. APIs can be public, paid, or even for private or limited use. This will depend on the company's objective and the type of solution it wants to deliver. We have listed some famous examples of APIs:

### **Famous APIs
**

**[shoptime](https://api-sandbox.bonmarketplace.com.br/explorer/)**
It uses an API, consuming services from Ipiranga's KM de Vantagens program. In other words, when a purchase is made through Shoptime, points are automatically earned in Ipiranga's mileage program. Both companies benefit from this type of partnership.
**[Take off](http://dev.despegar.com/)**
This company operates through intensive API consumption. All the information displayed to the end user has been previously verified with other companies. Every time a new query is made about any service that Decolar sells, several APIs are called to check the price and availability in real time. For these companies, Decolar functions as just another sales channel! 
**[Twitter](https://dev.twitter.com/rest/public)**
It uses a public API, but limits the number of times a program can access it per hour. This prevents the site from being attacked by... *Spammers* or have your user experience compromised due to excessive calls.
**[Apple](https://developer.apple.com/library/ios/navigation/)**
It has numerous **APIs** in their operating systems. This allows developers to use them to create *apps*provided they pay for it annually. In this way, the company controls the *with* which is made available to their systems, ensuring that they comply with certain security guidelines.
**[Windows](https://dev.windows.com/en-us/windows-10-for-developers)**
The company is releasing access to the vast majority of its APIs for free. The goal is to maintain a high number of applications, considering that Microsoft's operating system is one of the most widely used in the world. The same concept applies to the Xbox product, which already integrates with other company services via API.

## **Conclusion**

It is up to the developer to decide which will be most useful for the system they are working on. There are tens of thousands of **APIs** Available for free or paid use on the internet. Preferably, prioritize those with good documentation. This reduces the incidence of problems when implementing new functions in your software, in addition to providing more efficient error support.
There are, of course, cases where it's impossible to avoid using certain APIs. For example, you can't create a Twitter-based application without adhering to the social network's API usage rules. But this isn't a problem if they're used effectively. By opening your application's windows to the world, you generate increased user engagement and a dynamic, error-free app.
