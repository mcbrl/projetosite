## **The features of Liferay DXP 7.1**

Liferay Digital Experience Platform version 7.1 is even better. It can be the ideal solution for Portals, Intranets, Self-Service Sites, Websites, Integration Platforms, and Enterprise Solutions.

This new version has been greatly improved by offering tailored solutions. Furthermore, it is compatible with third-party software and has complete integration through APIs and Web Services, which facilitates integration with legacy systems.

The entire customer journey takes place on a single digital platform. This is achieved with stability, flexibility, scalability, and security, all within a high-level platform.

Below are some of the potential features of this tool in more detail:

## **Horizontal Portal**

Liferay DXP 7.1 is an increasingly flexible and reliable platform, with excellent integration capabilities with backend systems – a key differentiator for horizontal portals. Backend APIs enable connections to digital assets, caching, comments, databases, document management, geolocation, access policies, message busing, permissions, recycle bin, task scheduler, dynamic scripts, contextual search, and workflow.

[Liferay is a leader in Gartner's DXP quadrant – Find out why.](/en/Why-Liferay-is-a-leader-in-Gartner%27s-Digital-Experience-Platforms-quadrant/)

The setup process is quick, making tasks that are typically time-consuming, such as changing a page layout, much simpler within an intuitive and responsive interface.

Availability (uptime) and scalability are constantly improving, supporting increasingly complex environments with millions of accesses and users.

The development languages ​​and UI frameworks include: Java, JSF, Lexicon, Groovy, GWT, jQuery, Twitter Bootstrap, Metal.js, ReactJS, AngularJS, Senna.js, Lodash, Vaadin, Ruby, Scala, Freemarker, among others.

A major advantage of Liferay DXP 7.1 is Dynamic Virtual Hosting. This means that a single instance can be duplicated to quickly create websites hosted on a Liferay implementation. Each clone can have a unique URL, as well as a custom theme and design.        

## **content management**

“Personalized Experiences” are the cornerstone of Liferay DXP 7.1. The engineering team took great care to strictly follow this new market trend.

Page Fragments are components designed to be reusable, used to quickly create new pages. Fragments use *inline* editing to change text and images.

With Liferay DXP, it's possible for various types of users to access a single page view on a single URL. You can customize page views according to the user's role, group, organization, or personal preferences.

## **Collaboration and Engagement**

Liferay DXP 7.1's collaboration and engagement applications leverage WYSIWYG interfaces, ranking, comments, tag categories, related content, attachments, inappropriate content flagging, reader subscriptions, and RSS feeds.

Another major advantage is the ability to tag web content, which allows for dynamic sharing of content with other users. In addition to this advantage, there is also the optimized use of ads, allowing for targeting according to the audience.

## **Digital Asset Management (DAM) and Enterprise File Sync and Sharing (EFSS)**

This allows for the efficient organization and sharing of resources and content within a single system. It enables the management of documents, videos, audio, images, and other media types in a unified repository.

Sharing is taken so seriously that real-time document synchronization is allowed across mobile and desktop environments. Furthermore, there's WebDAV functionality, enabling users to access shared content across different browsers.

There is also the option to share files by creating shortcuts to Google Drive files in the Documents and Media repositories. This way, files can be managed within a Liferay DXP website.

## **Mobile Experience Platform**

Liferay DXP 7.1 offers a very flexible mobile experience. You can count on responsive design, hybrid apps, fully native apps, or any combination of them.

The Liferay DXP CSS framework is designed to work with browsers on all platforms and page *previews* , and is available for any screen size. The platform also features the concept of "Adaptive Media," which dynamically adjusts images to the screen size of each device.

Another advantage is the **Mobile Sync App** , which allows users to share files across multiple devices with most of the features available on a desktop.

## **Smart Forms, Workflows, Business Process Automation**

A complete digital experience leads to process improvement. Liferay DXP 7.1 is a master at this! With this platform, it's possible to streamline common processes and gather strategic and essential information from your users.

Save your time! With Liferay DXP you can create forms for everything. This ranges from automating business processes to replacing complex applications. In DXP 7.1 you can validate entered data, apply conditional rules, authenticate users, and much more.

The form also supports variations in language and context depending on the location. This is important for more accurate global support, including situations where language fields require different formats depending on the country (for example, address and date formats).

## **Development Tools**

Developing, managing, and maintaining a digital asset in Liferay DXP 7.1 is straightforward. This platform features a comprehensive integrated IDE for creating applications and modules. The "Developer Studio" simplifies the use of project creation wizards to build modular projects based on Maven, Gradle, and bndtools.

Another great help is the Liferay Marketplace. It allows developers to sell, share, and download themes, integration plugins, and entire applications created in Liferay DXP.
