The Liferay DXP platform has a robust tool that enables the creation of websites for the internet and/or intranet in a practical, flexible, multilingual way, in addition to many other features, including SEO (Search Engine Optimization).

Within a company, there are several strategies that can be adopted to attract more customers, and the creation of organic content is one of them. When we talk about SEO, companies need to worry about issues that go far beyond quality content; having a secure and efficient platform is fundamental.

But is it possible to have a lightweight portal with a satisfactory user experience and optimized for SEO? The answer is, yes!

To optimize content so that it can be reached organically, it's easy to configure in the Liferay portal; just follow a few steps for implementation.

Check out the article written by our software architect, Henrique Andrade, and learn how to configure your Liferay platform!

## Setting up Liferay DXP for your SEO strategy

Once the page is created and its content is ready to begin your SEO strategy with [Liferay DXP](/en/dxp--cms--or-portal%3A-which-is-the-best-tool-for-creating-impactful-digital-journeys/) , the manager can access the area for defining the attributes that will be specifically used by search engines.

The example below shows some of the fields that can be filled in to customize how the page should be displayed:

![](/wp-content/uploads/2023/04/SEO_1.png)

All common SEO attributes are available for completion, and there is also a preview of how the page will be displayed in search engines.

![](/wp-content/uploads/2023/04/SEO_2.png)

For portals with internationalization, it is possible to define specific (translated) content for each language by simply clicking on the flag next to each field and filling it in:

![](/wp-content/uploads/2023/04/SEO_3.png)

## Liferay DXP Open Graph

In addition to fine-tuning for SEO specifically, the Liferay portal offers another very important feature for any website that needs a good social media presence.

In the page settings, it's possible to define specific attributes in a user-friendly form, and once completed, all the necessary tags according to the Open Graph specification will be added to the page transparently to the administrator.

In the example below, we have the form with the fields that can be defined, including for each language through the flag:

![](/wp-content/uploads/2023/04/SEO_4.png)

After filling in the required fields, a preview will be displayed showing how the page might appear on a Facebook timeline, for example:

![](/wp-content/uploads/2023/04/SEO_5.png)

## Custom markers (meta)

In addition to SEO and Open Graph settings, it's possible to easily add additional meta tags to the page if needed, without having to edit HTML code directly. Simply access the "Custom Tags" feature and fill in the required information. You can have multiple tags, and it's also internationalized.

![](/wp-content/uploads/2023/04/SEO_6.png)

## Automatically generated HTML

On a more technical note, these attributes will be automatically included on the page after the Open Graph and/or SEO fields are filled in for the page:

## SEO analysis integrated with Google PageSpeed ​​Insights

In the Liferay portal, it's possible to configure your website to use your Google [PageSpeed ​​Insights](https://pagespeed.web.dev/) API key . Once the key is configured, the website's content manager will have access to a preview of page performance, integrated with the portal.

The example below summarizes the main points identified by Google PageSpeed ​​Insights, which can be viewed directly on the portal:
