Docker and MuleSoft together?

It looks like something good is coming!

Recently the [Docker](/en/docker/) announced a partnership with [MuleSoft](/en/mulesoft/) which promises to enhance the digital transformation process for its clients.

A convergence of forces between SaaS, IoT, Cloud, and Mobile has brought unprecedented demands for companies to accelerate their innovation and meet constantly changing needs.

*It's not the big fish that eats the small fish. It's the fast fish that eats the slow fish.*

Several solutions have already been made available for this problem of acceleration – from harder work to outsourcing and... [**DevOps**](/en/What-is-DevOps/)However, none of these solutions truly offered the necessary levels of acceleration. And the reason is clear: there is too much friction hindering the possibilities.

**Docker** e **MuleSoft** They eliminate friction in the innovation process, from conception to implementation.

MuleSoft offers a "top-down" architectural approach, with design and deployment. **"API-first"** (API first).

The Docker approach is **“bottom-up”**when viewed from the perspective of application containerization, both in modernizing traditional applications and in creating new applications.

![](/wp-content/uploads/2018/11/DOCKER-imagem.png)

The combination of these two approaches, along with the proposed platform, tools, and methodology, allows both organizations to help your company modernize faster than ever before.

Docker and MuleSoft bridge the gap between infrastructure and services in a way never before achieved in the industry.

Docker and MuleSoft together accelerate the modernization of legacy systems and the delivery of new applications, reducing IT complexity and costs.

 With both, it is possible to achieve the following objectives:

1) Modernize traditional applications quickly, without code changes, using the methodology and tools of the Docker Enterprise container platform, which are used to containerize legacy applications.

Next, you can instantly extend your business logic and data to new applications by leveraging MuleSoft's API Gateway and Anypoint Platform.

[API Gateway or API Manager? Find out who's who.](/en/API-gateway-or-API-management/)

2) Accelerate the time to launch of new applications, improving developer productivity and collaboration, and enabling greater reuse of application services.

O **Anypoint** **Studio** It allows you to define API contracts and decouple consumers and producers of microservices, so that line-of-business developers consuming the API can start creating innovations immediately (such as a mobile application) using services. **“mockdata”** Nowhere.

Docker Desktop is used today by millions of developers to develop microservices using any language and framework.

Microservices developers can take advantage of **DockerDesktop** To implement the APIs using the best tool for the job and focus on implementing the business logic with a clear specification defined in the Anypoint Platform.

This allows the **Anypoint Platform** Provide an additional layer of security, observability, and manageability at the API level.

3) Improve the overall security, manageability, and monitoring capabilities of the application using the **DockerEnterprise** to manage container workloads and the MuleSoft Anypoint Platform to run and manage the application network.

![](/wp-content/uploads/2018/11/DOCKER-imagem.png)
With this partnership, Docker and MuleSoft promise a complete solution, tools, methodology, and know-how to execute a multifaceted approach to promote profound transformation in your business.
