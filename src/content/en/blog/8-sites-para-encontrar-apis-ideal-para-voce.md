We've compiled a list of 8 websites to help you find APIs that run various types of solutions in building your IT project. In addition, we've also reviewed each site to guide you.

If you already know [what an API is](/en/What-is-API-Understand-it-in-a-simple-way./) , check out this content to learn how an [API Gateway and an API Manager](/en/API-gateway-or-API-management/) can enhance its use.

Also, check out our post about ["4 Tips to Increase Engagement on Your API"](https://blog.vertigo.com.br/4-dicas-para-aumentar-o-engajamento-na-sua-api/?_fs=c9fcaf60-1bbe-4917-9b91-b09869a8dc77) . If you're starting an **API** strategy , you need some models to use as a reference.

Getting back on track, we've listed 8 websites below that can greatly help you with this task.

## 1: [ProgrammableWeb](http://www.programmableweb.com)

Upon accessing the website, the user has access to announcements related to Application Programming Interfaces, news reports, and comments.

By accessing the page, you have the opportunity to take advantage **of the world's largest API directory** ! In addition, the site also catalogs mashups and development tools for SDKs, frameworks, libraries, and code samples.

[![](/wp-content/uploads/2018/03/PW.png)](http://www.programmableweb.com)

They also produce their own content about APIs, publishing articles on updates, code tutorials, comments, etc. Through internal data and market research, they also provide relevant content on [the API Economics](https://blog.vertigo.com.br/parte-1-a-economia-das-apis-ja-esta-aqui-voce-esta-pronto/?_fs=c9fcaf60-1bbe-4917-9b91-b09869a8dc77) . It's worth adding this site to your favorites!

## 2: [PublicAPIs.com](https://www.publicapis.com/)

Visitors can search and compare the functionalities between the various existing APIs, including those from NASA, PayPal, and others.

It's possible to include brief descriptions and links to the documentation from the developers. If you want to create your own API and don't have any to use as a reference, you're likely to find a solution to get your project started.

[![](/wp-content/uploads/2018/03/publicapis.com-API-discovery-nordic-apis-1024x634-1.png)](https://www.publicapis.com/)

Visitors can also suggest new application programming interfaces to expand the directory.

## 3: [APIs.io](http://apis.io/)

This site is maintained by 3Scale, API Evangelist, and API Tools. They use metadata search to find the API you are looking for. Because of this search model, it stands out as a scalable alternative to traditional API cataloging methods.

The website is a leading reference in the technology world and is listed as one of the top reliable search sources for experts. 

[![](/wp-content/uploads/2018/03/apis.io-API-discovery-nordic-apis.png)](http://apis.io/)

## **4:** [**Algorithm**](https://algorithmia.com/algorithms)

The site's highlight is the possibility for mathematicians to make their algorithms available for the development of intelligent tools. Solutions for integrating applications using machine learning in the areas of audio, video, and mathematics are leveraged in other projects. This makes the site an excellent repository of APIs.

[![](/wp-content/uploads/2018/03/algorithmia.png)](https://algorithmia.com/algorithms)

## **5:** [**Product Hunt**](https://www.producthunt.com/#!/s/posts/api)

Through a collaborative community similar to Reddit, various APIs are shared and organized into lists.

For those seeking an informative environment with up-to-date information, the site is an excellent option in the search for smart solutions.

[![](/wp-content/uploads/2018/03/producthunt.png)](https://www.producthunt.com/)

## 6: [Google APIs Discovery Service](https://developers.google.com/discovery/)

This website brings together various Google APIs and returns data about them through a "lightweight, JSON-based API that exposes machine-readable metadata." This tool provides interactive insights for both machines and the human eye.

The user experience is enhanced through an explanatory video during access. It's worth checking out!

[![](/wp-content/uploads/2018/03/google-apis-discovery.png)](https://developers.google.com/discovery/)

## **7:** [**API Harmony**](https://apiharmony-open.mybluemix.net/public)

Browse IBM's API directories and discover solutions that meet your needs in a variety of contexts.

The site is organized into lists and highlights the most popular APIs; in addition, it has a space for discussion between developers and GitHub projects.

[![](/wp-content/uploads/2018/03/apiharmony.png)](https://apiharmony-open.mybluemix.net/public)

**8:** [**Azure Marketplace**](https://docs.microsoft.com/pt-br/azure/?product=featured) **by Microsoft**

These are APIs that revolve around Microsoft Azure, a platform dedicated to running various cloud applications for building innovative projects in pursuit of [digital transformation](/en/Digital-transformation%3A-are-you-ready/) . You can register for free on the platform.

The API can be accessed for various solutions, including Azure Kubernetes. If you are a developer, you will find quality material while browsing the website.

[![](/wp-content/uploads/2018/03/azure-microsoft-nordic-apis.png)](https://docs.microsoft.com/pt-br/azure/?product=featured)

## **I want to know more about APIs!**

APIs are becoming increasingly prevalent in our current economy. The way technology is cataloged and found is becoming a growing concern, because what isn't found isn't used. It's that simple!

It's interesting that the thinking regarding the use of an **API** is the same as that of a product. Developers should consider all possible marketing actions (yes, Marketing and IT should think together about an API strategy). In this space, Digital Marketing strategies are fundamental. A very simple tip: look for directories like the ones mentioned to add your API and increase its exposure and relevance!
