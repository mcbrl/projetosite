## API virtualization

Developing a new **API** – whether [public or private](https://blog.vertigo.com.br/api-publica-ou-privada-como-saber/) – requires careful attention to ensure it can perform its function efficiently. Depending on the company's objective, an API might handle financial transactions or simply display information from a social media profile, but errors can have catastrophic consequences.

Some simple problems that can compromise a company's security and operations can be easily prevented with a simple piece of advice: **test your API** . But to do that, you first need to fully implement it, right?

Actually, no: there is a way to create a safe and economical environment for these tests, and this process is called **API virtualization** . Simulation environments are not a strange concept in web development. Especially when it comes to APIs, which sometimes need to simulate a part of their service for testing purposes, virtualization is an option that can go beyond just testing your API.

Following the same concept as the [Dropbox API](http://www.programmableweb.com/news/dropbox-releases-api-explorer-to-test-api-calls/2015/08/21) , [Amazon](http://www.programmableweb.com/news/amazon-announces-mock-integration-feature-api-gateway/brief/2015/09/03) recently announced a simulation integration feature for its API gateway. Virtualization takes this simulation a step further, allowing simulated API calls and responses to be coded during the development stage, thus enabling API providers and developers to measure performance in a highly refined way before the official launch.

In this post you will understand what it does, and what the advantages are of using virtualization to test an API. Follow along:

## What is API virtualization?

Virtualization is when an environment is created to simulate *software* running based on another program. This is very common with virtual operating systems, such as programs that allow Windows to run within OSX or Android within iOS, for example.

In the case of [API](/en/What-is-API-Understand-it-in-a-simple-way./) virtualization , things are a little different: since many APIs work with cloud platforms, it's necessary to simulate these systems so that they can be tested without integrating with the original system. Applying this idea brings several possibilities and advantages for developers, and we'll show you 5 of them so you can better understand why API virtualization can be interesting.

## 1\. Test your API in a secure environment.

A malfunctioning API may simply fail to perform its function, but it can also interfere with other system processes and create difficulties for users. By performing tests through API virtualization, you can avoid bigger problems, understand the API's behavior, identify problems before other users encounter them, and find ways to remedy these failures. 

## 2\. Test your API by simulating problems.

Have you seen how function error messages appear to the user? How do frequency limits work? During the final stages of development, it's important to know how your API responds to system errors and problems. To make this possible, API virtualization allows you to create extreme situations through simulations, so you can analyze error messages, failures, and response speed, for example, to correct them. 

## 3\. Virtualizing APIs increases your productivity.

With API virtualization, your developers don't need to waste time programming specific tests to evaluate an API, and can dedicate that time to improving integration and fixing bugs found through simulation.

## 4\. Testing with API virtualization is cost-effective.

Saving developers time so they can produce more efficiently is also cost-effective, as projects take less time and it's possible to develop more solutions in less time. It's also worth considering the major benefit of performing tests through API virtualization: fewer errors that would cause the platform to become unavailable, lower repair costs, and the ability to predict and resolve problems before they occur.

## 5\. Your API will be ready sooner.

By combining the aforementioned benefits, faster completion is what brings more agility to a business. Developers can work more efficiently and correct important errors, which means that your API is ready to be integrated – without risks to the system – in a much shorter period of time than would be necessary without testing with API virtualization.

## Conclusion

#### Benefits of API virtualization

API virtualization brings several benefits, such as:

- Increased productivity;
- Shorter time to market for your API;
- Testing real-world scenarios without the risk;
- Eliminate the need for individual developers to write and rewrite their own simulations.
