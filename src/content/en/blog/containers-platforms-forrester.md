Forrester recently published the report **Forrester New Wave™: Enterprise Container Platform Software Suites, Q4 2018.** The report presents the leading vendors of so-called **Enterprise Container Platforms (ECP)**.

Eight of the most significant vendors in the category were identified – [Docker](/en/docker/) , IBM, Mesosphere, Pivotal, Platform9, Rancher Labs, Red Hat, and SUSE. Docker was ranked as a *Leader*.

This report details each vendor's performance against 10 criteria and where they compare to one another. Enterprise architects can use this review to select the right partner for their **enterprise container platform needs.**

[Click here to view the full report.](https://reprints.forrester.com/#/assets/2/1492/RES141562/reports)

## About the Enterprise Container Platforms

For a while there was some confusion in the market between Orchestration Solutions and Container Platforms. However, in 2018 we have seen greater alignment among the leading industry analysts regarding the definition of container platforms.

This report is based on a multidimensional review of enterprise container platform solutions that go beyond runtime and orchestration, including:

- Image management;
- Operations management;
- Security features;
- User experience;
- Application lifecycle management;
- Integrations and APIs.

## The role of container platforms  

As the adoption of container technologies continues to advance and mature, companies now recognize the importance of an *enterprise container platform*.

Container technology goes beyond simply providing a *runtime* for applications. It offers a comprehensive management framework designed to protect and operate containerized applications at scale throughout the software lifecycle.

Initially, containers may have represented a revolution in how developers package applications. However, container platforms are driving a shift in how companies manage and secure legacy applications and mission-critical microservices, both *on-premises* and across multiple clouds.

Companies are beginning to realize that *container engines* and orchestration technologies alone do not solve critical problems.

- Where did this app come from?
- Was the app developed with company and/or industry best practices in mind?
- Has this app undergone a security review?
- Is my cluster running as expected?
- If my application is crashing or performing poorly, where should I look for a solution?
- Will this environment run the same way on the new hardware/cloud we are using?
- Can I use my existing infrastructure and/or tools with this container environment?

## Enterprise Container Platform: the Docker approach

Docker is committed to providing a container platform grounded in the values ​​of choice, agility, and security. Currently , Docker Enterprise Edition is used in over 650 organizations worldwide.

The container platform developed by Docker supports a wide range of use cases and can run on a variety of infrastructures, including private *data centers* and public clouds.

Docker customers have observed a significant reduction in infrastructure costs, increased operational efficiency, and enhanced security as a result of containerization.

Docker Enterprise Edition has as one of its main focuses being an enterprise solution for all applications, including [Windows Server applications](https://www.docker.com/products/windows-containers) . Although containers originated in the Linux Operating System, Windows Server applications now represent more than 50% of all enterprise applications in operation.

Partnering with Microsoft since its inception, Docker has been helping organizations containerize and operate Windows Server applications in production for over two years—and counting. Most importantly, the Docker container platform addresses Windows Server and Linux applications, from image management to operations management, integrated security features, user experience, and much more!

Thus, Docker remains the segment leader, topping the Forrester New Wave report, and focuses on expanding its reach to increase its customer base, while continuing to refine its container platform strategy.
