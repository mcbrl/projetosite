## Did you know that Application Programming Interfaces can also have different types and functionalities?

Know that they possess these qualities, and understanding them makes all the difference. It can be the key to achieving the results your company desires. All this with security and efficiency, potentially boosting various types of businesses.

Below is a brief overview of the types of API products:

## API Gateway

API Gateway creates a single point of access, filtering who accesses your APIs. Think of an **API Gateway** as a tool for redirecting and filtering third-party traffic.

## APIManager

This type of product provides a management layer for API Gateways. In addition to defining the API Gateway's behavior, the API Manager handles analysis of each request, provides corporate insights through analytics, implements version control, creates access dashboards, enables monetization, and more.

## What is an API Gateway?

The Portuguese translation of the word "Gateway" is Portão (Gate). The name is not accidental, as this API product operates similarly. This Application Programming Interface serves to filter the types of requests that will occur with the API.

This technology is already adopted by several companies worldwide and is offered by various companies, such as [Mulesoft API . Here are some](/en/mulesoft/) **API Gateway** functions :

- *Single point of access to all APIs*, positioning itself between its APIs and their respective users.
- *Input data filtering*It can redirect the API call to the correct location based on various input parameters, and even ignore the request if desired, without sending traffic to your API. It's the sentinel at your gate.
- *Security mechanisms*, which include user authentication and access logs.
- *User-based access restriction, which allows limiting a user's access to a specific resource based on various criteria, such as the number of requests in a month or in the last 10 seconds.*

These features present in the **API Gateway** offer a wide range of advantages for companies that adopt them. A single access point, for example, means reduced effort in managing the "entry points" of their web services, allowing them to focus their efforts in a single location.

Furthermore, the combination of the other gateway functions mentioned in the topics above allows all this processing to be performed outside of your API, reducing its complexity. This leads to cost reductions in maintaining them, opening doors for the development of even more **APIs**.

To further reduce the cost of exposing multiple APIs in the air, API Gateways commonly unify access to internal APIs, whether they originate from legacy systems or more dynamic microservices. ## **So what is an API Manager?**

API **Manager** is software that implements a management layer on top of an API Gateway, including features to facilitate its management and enabling the visualization of business data. This provides the generation of usage statistics, API lifecycle management, among other advantages.

In addition to gateway functions, the **API Manager** can offer a wide range of possibilities to leverage your API suite:

- Corporate insights from APIs through dashboards.
- API lifecycle management.
- API prototyping, API versioning.
- Potential for monetizing APIs.
