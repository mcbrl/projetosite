## New features and improvements in Liferay DXP 7.4

Liferay DXP 7.4 brought several improvements to deliver exceptional digital experiences. Some of the main highlights are:

**Optimizing Digital Experiences with Data-Driven Insights**

- Advanced A/B testing with the ability to select any clickable element on a page to perform tests.
- Enhanced Content Dashboard with an audit tool to filter content by category.

**Empowering Professionals to Create Excellent Digital Experiences**

- Asset libraries allow you to create display page templates for web content and document types.
- Enhanced navigation menus with the option to use display pages as items.
- Creating display pages categorized by specific categories.

**Creating More Seamless B2B Shopping Experiences**

- Prices and discounts are customized according to the specific conditions of the order.
- Account management widget with a clear visual representation of the organizational structure.

**Low-Code/No-Code Resources for Creating Innovative Digital Experiences**

- Adaptive media for displaying images of appropriate size according to the width of the viewing window.
- Enhanced collection display with filtering, search, and sorting capabilities.
- Liferay objects allows the creation of custom business objects without the need for developers.

**Reducing the Cost and Effort in Creating and Maintaining Digital Experiences**

- Content libraries with staging support for sharing content across multiple websites.
- Setting expiration dates for documents and media allows for greater control over displayed content.
- Unified user experience for forms, web content, documents, and media.

**Enhanced Collaboration and Sharing**

- Publications with simplified collaboration that allow you to invite colleagues to participate and collaborate.
- Optimized Search Reindexing with action scope limited to selected virtual instances.

**Integration with Liferay Enterprise Search**

- Liferay Enterprise Search features are natively available with an active subscription.

**Resources for Protocol and Integration Support**

- Multifactor authentication with FIDO2 support for enhanced security.
- Simplified OAuth2 administration and OpenID Connect via proxy for integration with other platforms.
- Remote applications for web components offer greater flexibility and dynamism in development.

These enhancements make Liferay DXP 7.4 an even more complete and efficient digital platform for delivering exceptional and personalized digital experiences to users.
